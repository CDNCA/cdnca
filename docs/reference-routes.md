# 参考路由清单

快照日期：2026-07-21  
参考站：参考系统演示环境（地址略）

本清单来自参考系统演示环境两角色 `/v1/common/menu2` 返回值和前端编译路由。临时只读会话只用于读取菜单和当前用户类型，没有创建、修改或删除业务数据。

官方帮助站的 136 个侧栏页面已另行逐页审阅，字段和工作流补证见 [帮助站页面级清单](help-doc-inventory.md) 与 [帮助工作流](help-workflows/)。帮助文档不能替代本清单要求的演示 UI 页面审计，因此下表未采集的页面仍保持“待审”。

用户另提供了一个已登录的真实客户实例用于只读补证。其用户端工作台、网站/证书、刷新预热、安全规则、监控日志、四层、套餐和账户体验见 [客户实例用户端体验补充](ui-audit/customer-user-experience.md)。该证据不改变本表对参考系统演示页面的“待审”状态，也不包含客户业务数据。

下文共有 65 个以路径开头的记录行：其中 64 个是页面路由，另 1 个是“路由差异”表中的 `/log` 顶栏定位复核项。页面路由验收总数以 64 为准，路径记录行总数以 65 为准。

## 状态说明

- `observed/menu`：该角色菜单接口直接返回此项。
- `observed/menu-hidden`：该角色菜单接口返回此项，但同时带有 `auth: ["hidden"]`，不是可见侧栏入口。
- `observed/router`：当前前端编译资源中存在路由，但它可能是隐藏详情页、错误页或未出现在该角色菜单中。
- `待审`：尚未用真实浏览器逐页记录 DOM、字段、弹窗、加载/空/错误/无权限状态和响应式截图。本次内置浏览器不可用，因此所有页面都保持待审，不能把菜单存在误写成页面验收完成。
- 路由器基路径为 `/dashboard/`。下表应用内路径 `/site/list` 的完整路径是 `/dashboard/site/list`。
- 菜单可见性不等于 API 授权结论。尤其是前端包包含两角色共用路由，必须另做直接 URL 和 API 越权测试。

角色缩写：`A` = 管理员，`U` = 普通用户，`P` = 未登录访客。

## 已发现但需特别复核的路由差异

| 差异 | 当前证据 | 处理方式 |
| --- | --- | --- |
| 前端旧静态菜单片段出现 `/stream/realtime`，当前两角色动态菜单使用 `/monitor/stream/realtime` | `observed/router` 与 `observed/menu` 不一致 | 以当前动态菜单为基线；浏览器复核旧路径是重定向、兼容别名还是 404 后再决定是否保留别名 |
| 前端路由资源包含两角色全部页面，但菜单只按角色下发子集 | `observed/router` | 不能依赖前端隐藏；逐路由做页面和 API 双层 403 测试 |
| 管理员菜单复用 `/user-package/usage`，其余 `/user-package/*` 仅用户可见 | `observed/menu` | 验证管理员筛选范围、用户租户范围和 URL 参数越权 |
| `/log` 位于“日志”顶栏而非首页侧栏 | `observed/menu` | 复刻顶部入口和隐藏侧栏行为，确认生产环境是否默认显示 |
| 更新日志提到旧 UI `/console/index.html#/user/login` 仍可用 | `update-log` master v5.7.0 | 新系统不默认复制旧技术栈；先确认兼容 URL 是否仍是交付要求，必要时仅做重定向/兼容入口 |

## 逐页审计记录模板

每个待审页面完成后追加证据链接，并至少记录：

1. 角色、完整 URL、窗口尺寸、采集时间和参考版本。
2. 左侧导航、顶部栏、标题、面包屑、工具栏、表格列、分页和默认筛选。
3. 创建、编辑、查看、删除确认、批量操作及所有抽屉/弹窗字段。
4. 加载、空数据、接口错误、校验错误、无权限和部分失败状态。
5. 桌面常用宽度、窄屏和移动端截图；溢出、遮挡、焦点和键盘操作结果。
6. 页面请求的 API、必要权限、成功/失败响应形状和是否包含敏感数据。
