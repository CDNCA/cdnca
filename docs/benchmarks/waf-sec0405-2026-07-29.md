# SEC-04/05 Edge WAF evaluator benchmark evidence

## 当前状态

final new-byte OpenResty smoke 已完成并通过；replacement 五轮 benchmark 尚未执行。当前有 6 个不属于 WAF 的 NodeSeek/MeshBoard 容器在运行，隔离条件不成立，且本任务无权清理它们，因此 replacement 状态为 `PENDING`。

此前耗时 79.656s 的五轮发生在最终 `validRequest` 生产字节和本次正式 smoke 之前，现标记为 `SUPERSEDED/PRE-REVIEW`，不得称为 final 或用于切换默认实现。它的完整统计和原始输出保留在本文中，不删除历史证据。

更早的两次五轮预跑与共享 Docker/Updater/OBS 或其他系统负载重叠，同一二进制、同一 fixture 的 ns/op 最高出现约 19.9 倍波动。它们继续标记为 `INVALID`，不参与默认切换判断。原始输出全部保留在本文末尾；B/op 与 allocs/op 跨轮稳定，但不足以推翻时间测量的不确定性。

生产默认继续保持线性两阶段有序扫描，test-only `preindexedEvaluator` 不进入运行时。回退不需要 schema 或制品迁移：继续对同一 canonical policy 使用生产 `Evaluator`。后续只有 replacement 隔离五轮完成、目标节点复测、差分集扩大到每份 512 条规则并证明构建/常驻内存有界后，才进入 ADR 评估。

## 固定数据集

所有 policy 均经生产 `CompileJSON` 生成 canonical policy。规则顺序为 `priority` 后 `rule_id`；每次请求使用相同固定 UTC 时间。

| workload | 规则数 | 固定路径 |
| --- | ---: | --- |
| steady late match | 128 | 前 127 条 path miss，最后一条 block/stop 命中 |
| worst miss | 512 | 512 条 path 全部未命中 |
| multi CIDR | 512 | IPv4/IPv6 CIDR 交替，method 固定不匹配；candidate 按地址族预分组 |
| allowlist stop | 512 | 前 511 条 block miss，最后一条 allow/stop 命中 |
| continue chain | 512 | 全部 path 命中并 continue，混合 log/block，完整保留事件链 |
| index build | 512 | 每次从同一 canonical policy 新建 test-only family index |

`TestPreindexedEvaluatorMatchesLinear` 使用固定 seed `40405`，对 200 份含 1 到 64 条 allow/log/block、continue/stop、IPv4/IPv6 CIDR、无 CIDR及过期规则的 policy，各执行 12 个请求，共 2,400 组 linear/candidate deep equality。focused ordinary test 在本轮通过。该差分集尚未扩到每份 512 条规则，因此它是保留 candidate 继续测量的依据，不是默认切换证明。
